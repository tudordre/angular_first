# angular_first

Proiect Angular de bază creat pentru testare și dezvoltare locală.

Prerechizite:
- Node v24.15.0
- npm
- Angular CLI (opțional: npx @angular/cli)

Instalare și rulare:
```bash
npm install
npx ng serve --host 0.0.0.0 --port 4200 --open
```
